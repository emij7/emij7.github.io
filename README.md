# Ignacio Emiliano Juarez — Portfolio

Personal portfolio built with Next.js, React and Tailwind CSS. It presents professional experience, selected production projects and a full-stack profile while preserving the site’s Batman-inspired visual identity and 3D elements.

The portfolio supports English and Spanish, is statically exported for GitHub Pages and includes responsive, reduced-motion and low-cost mobile fallbacks.

## Main stack

- Next.js 14 and React 18
- Tailwind CSS
- Framer Motion
- React Three Fiber / Three.js
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Create a production export with `npm run build`.
